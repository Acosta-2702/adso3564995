01-Emmet

Plugin for faster HTML and CSS coding.

01-Child >

Creates child elements (nesting).

Example:

ul>li>a ↔️

Result:

<ul> <li> <a href="">Link</a> </li> </ul>

02-Sibling +

Creates sibling elements.

Example:

header+section+footer ↔️

Result:

<header></header> <section></section> <footer></footer>

03-Multiplication *

Repeats elements multiple times.

Example:

ul>li*3 ↔️

Result:

<ul> <li></li> <li></li> <li></li> </ul>

04-Class .

Creates a class attribute.

Examples:

div.important ↔️

.danger ↔️

Results:

<div class="important"></div> <div class="danger"></div>

05-Classes ...

Creates multiple class attributes.

Example:

div.red.green.blue ↔️

Result:

<div class="red green blue"></div>

06-Identificacion #

Creates an ID attribute.

Example:

menu#cod123 ↔️

Result:

<menu id="cod123"></menu>

07-Text {}

Inserts text content.

Examples:

p{Lorem ipsum Dolor} ↔️

a{click aqui} ↔️

Results:

<p>lorem ipsum dolor</p> <a href="">click aqui</a>

08-Custom Attributes []

Creates custom attributes.

Example:

input[type=number]↔️

Result:

<input type="number" />

09-Item Numbering $

Adds consecutive numbers.

Example:

ul>li.option$$*3 ↔️

Result:

<ul> <li class="option01"></li> <li class="option02"></li> <li class="option03"></li> </ul>

10-Reverse Numbering @-

Inverts numbering order.

Example:

ul>li.num$@-3 ↔️

Result:

<ul> <li class="num">3</li> <li class="num">2</li> <li class="num">1</li> </ul>

11-Base Numbering @n

Defines a base number for sequences.

Example:

ul>li.num$@3*4 ↔️

Result:

<ul> <li class="num">3</li> <li class="num">4</li> <li class="num">5</li> <li class="num">6</li> </ul>

12-Climb Up ^

Moves up one level.

Example:

section>article>div^p ↔️

Result:

<section> <article> <div></div> </article> <p></p> </section>

13-Grouping ()

Groups elements together.

Example:

(header>nav)(section>article) ↔️

Result:

<header> <nav></nav> </header> <section> <article></article> </section>

14-Lorem Lorem

Generates placeholder text.

Examples:

lorem ↔️

lorem20 ↔️

lorem*5 ↔️

Results:

Lorem

15-HTML Documents Html:

Creates various HTML document types.

Examples:

html:xs ↔️

html:xt ↔️

html:4s ↔️

html:4ts ↔️

html:5 ↔️

Results:

<html:xs></html:xs> <html:xt></html:xt> <html:4s></html:4s> <html:4ts></html:4ts> <html:5></html:5>

16-Meta Tags Meta:

Generates meta tags.

Example:

meta:vp ↔️

Result:

<meta name="viewport" content="width=device-width, initial-scale=1.0" />
